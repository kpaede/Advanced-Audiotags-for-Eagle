Help & backups

Edit values directly. Custom names can be edited in the Name column. Right-click a row or open Tools for more actions. ␀ represents a NUL character; it separates text values in ID3v2.4 and APE, not in every tag format.

Saving creates a backup and verifies that audio bytes remain unchanged. Backups are stored in “Advanced Audiotags Backups” in Eagle’s application data.

Raw AC3 has no standard descriptive tagging scheme. Some players ignore or reject ID3/APE tags in AC3.
